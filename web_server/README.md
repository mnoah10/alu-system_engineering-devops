# web_server

Web server project scripts.

- 0-transfer_file: transfers a file to a server with scp
- 1-install_nginx_web_server: installs nginx and serves Holberton School
- 2-setup_a_domain_name: the domain name pointing to web-01
- 3-redirection: configures a 301 redirection on /redirect_me
- 4-not_found_page_404: configures a custom 404 page
- 5-design_a_beautiful_404_page.html: a custom designed 404 page
